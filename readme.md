# Explorer `.gitignore` Toggle

Enhance your workflow by quickly and conveniently toggling the visibility of
files ignored by Git in the Explorer panel!

## Installation

Install this extension from either registry:

- [Visual Studio Marketplace][marketplace] for Visual Studio Code
- [Open VSX][open-vsx] for VSCodium and other compatible editors

# Releasing

Releases are published from GitHub Actions to the Visual Studio Marketplace and
Open VSX. The workflow packages the extension once and publishes the same VSIX
to both registries.
